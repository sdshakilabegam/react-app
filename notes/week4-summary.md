# Week 4 Summary: React Fundamentals

- Monday: State and events. useState, onClick, re-rendering. Props vs state.
- Tuesday: Conditional rendering (if, ternary, &&) and lists with map() and keys.
- Wednesday: Forms. Controlled inputs, onChange, onSubmit, preventDefault, validation.
- Thursday: useEffect and the dependency array. Fetching API data with loading and error states.
- Friday: Mini project, a Task Tracker combining state, forms, lists and props.

## Key learning

State drives the screen: when state changes, React re-renders. Props pass data down.
Effects handle work outside rendering, such as API calls.

## Challenges

Keeping state updates immutable (spread operator), remembering keys in lists,
and handling the loading and error states for fetch.
